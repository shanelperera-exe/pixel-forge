# Inspiration

This directory records the sources, ideas, and original creators of UI components and patterns that have inspired the components within PixelForge.

## Source Documentation Convention
When adding a component inspired by or adapted from an external source, add an entry to `sources.md` in this directory and include an `Inspiration` section in the component's `README.md`.

For each source, document:
- Original source/Name
- URL
- Creator/Author (if known)
- License (if applicable)
- Date added
- Level of adaptation (e.g., "Inspired by", "Recreated from scratch", "Directly adapted from")
- Major modifications made

## Note on External Code
Do NOT blindly copy proprietary code. Distinguish between being "inspired by" a visual design versus "copying/adapting" the underlying implementation. Ensure appropriate licenses allow for the adaptation.
